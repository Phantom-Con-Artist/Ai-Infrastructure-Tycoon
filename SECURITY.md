# Security

It's an offline game, so the attack surface is small, but not zero (Electron, save files, IPC).

If you find something that could hurt players, for example a crafted save file that runs code, please report it
privately through [GitHub security advisories](https://github.com/Phantom-Con-Artist/Ai-Infrastructure-Tycoon/security/advisories/new)
rather than a public issue. We'll reply as soon as we can and credit you in the fix if you'd like.

Supported version: the latest release (currently **0.1.0 Beta**).
